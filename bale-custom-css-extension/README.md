# Bale Web Custom Layout

This unpacked Manifest V3 Chrome extension applies the requested layout CSS only on `https://web.bale.ai/*`.

## Install in Chrome

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked**.
4. Select this folder.
5. Reload any already-open Bale Web tab.

At desktop widths of 992px and above, drag the highlighted inner edge of the sidebar to resize it (from 280px to 720px). The chosen width is saved locally for the extension and restored on the next visit. The `.K4prvv` rule applies at every width.

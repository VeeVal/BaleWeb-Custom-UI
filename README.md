# Bale Web Custom Layout

Browser extensions that customize the desktop layout of [Bale Web](https://web.bale.ai/).

## What it changes

- Sets the default desktop sidebar width to 555px.
- Adds a draggable inner sidebar edge, with a saved width between 280px and 720px.
- Allows the content area to use the full browser width.

## Packages

- `bale-custom-css-extension/` — Chrome / Chromium Manifest V3 extension.
- `bale-custom-css-firefox/` — Firefox Manifest V3 extension.

Each package has its own installation instructions in its `README.md`.
